# AI伴读 - 沉浸式深度阅读伴侣

一款基于多模态大模型的沉浸式深度阅读伴侣应用。

## 功能特性

### 核心功能
- 📸 纸质书/任意文档瞬时数字化（OCR识别）
- 🎯 阅读意图导向初始化
- ✅ 精准溯源与事实核查
- 📊 全息人物/逻辑关系图谱
- ✨ 智能高亮与划词解析
- 📝 多维段落总结与大纲

### 沉浸体验
- 🎭 角色扮演式伴读
- 🔊 自定义声音克隆与多角色朗读
- 🎵 场景化氛围音效
- 🎨 画面脑补生成器

### 深度交互
- 🧪 知识迁移与生活实验室
- 💬 AI引导者深度探讨
- ✍️ 趣味"番外"分支创作

## 技术栈

- Flutter 3.0+
- Dart 3.0+
- Provider (状态管理)
- GoRouter (路由管理)

## 运行项目

1. 确保已安装 Flutter SDK
2. 运行 `flutter pub get` 安装依赖
3. 在 Android Studio 中选择虚拟设备
4. 点击运行按钮或使用命令 `flutter run`

## 项目结构

```
lib/
├── main.dart                 # 应用入口
├── models/                   # 数据模型
├── pages/                    # 页面
├── widgets/                  # 组件
├── services/                 # 服务层
└── routes/                   # 路由配置
```

## 注意事项

- 当前版本为交互原型，部分功能使用 Mock 数据
- OCR、语音合成、AI对话等功能需要对接实际API
- 建议使用 Android Studio 进行开发和调试
